# workstation-credentials

Веб-сервис для выдачи логинов и паролей рабочих мест участникам мероприятий: демо-экзаменов,
чемпионатов по программированию, сетевому и системному администрированию, лабораторных.

Участник открывает сайт и видит 6-значный код. Организатор в админке привязывает код к рабочему месту,
и страница участника сама показывает его доступы. Пароли не нужно печатать, диктовать или раздавать на бумаге.

- Несколько мероприятий параллельно. У каждого свои поля данных, свои карточки и свои рабочие места.
- Настройка в интерфейсе: поля, карточки, значки, живое превью. JSON не обязателен, но есть.
- Пароли рабочих мест хранятся зашифрованными, ключи лежат отдельно в `.env`. Паролей по умолчанию нет.
- Несколько администраторов с ролями «владелец» и «админ», журнал действий.
- Светлая и тёмная тема админки.
- Один контейнер, SQLite, внешние сервисы не нужны.

Стек: Python, Flask, SQLite, gunicorn, Docker.

## Быстрый старт

Для пробы на своей машине (Linux, WSL) домен и прокси не нужны. Нужны Docker с Compose и `python3`.

```bash
./setup.sh
docker compose up -d --build
docker compose exec web python manage.py create-admin     # или: ... manage.py demo
```

Участники: `http://localhost:8765/`, админка: `http://localhost:8765/admin/`.
В Windows с WSL нужен Docker Desktop с включённой интеграцией для вашего дистрибутива.

Боевая установка на сервере с доменом и HTTPS описана в [docs/deploy.md](docs/deploy.md).

## Разработка

```bash
pip install -r requirements-dev.txt
pytest

export $(python manage.py gen-keys | xargs) DB_PATH=/tmp/demo/creds.db
python manage.py demo
gunicorn --bind 127.0.0.1:8765 'app:create_app()'
```

Участник и админ должны быть в разных браузерах или в обычном окне и инкогнито: иначе у них общая сессия.

Шрифты Inter и JetBrains Mono лежат в `app/static/fonts`, лицензия OFL.

# Как проходит мероприятие

Один раз, заранее:

1. **Админы** (видит только владелец): завести остальных администраторов.
2. **Мероприятия → Новое мероприятие.** Можно начать с нуля, из готового шаблона (программирование, ИБ)
   или «по образцу» другого мероприятия.
3. Во вкладке **«Данные и страница участника»** описать, какие данные есть у каждого места
   (например «Хост», «Логин», «Пароль»; у пароля поставить «это пароль»),
   и собрать карточки, которые увидит участник. Справа живое превью.
   Вкладка **JSON** показывает то же самое текстом.
4. Во вкладке **«Рабочие места»** загрузить места из CSV (заготовку можно скачать там же) или добавить вручную.
   Первое поле данных служит названием места в списках.

В день мероприятия:

1. Участник открывает сайт и видит код.
2. Называет его организатору.
3. Организатор на странице **«Коды»** находит код, выбирает рабочее место и нажимает «Активировать».
   Страница участника сама обновляется и показывает его данные.
4. Список кодов обновляется кнопкой «Обновить». Сам он не прыгает, чтобы не сбивать при выдаче.

После мероприятия:

- **Закрыть мероприятие** отключает всех участников сразу.
- **Удалить** стирает мероприятие вместе с рабочими местами и паролями.

Пароли на странице участника скрыты точками, показываются кнопкой с глазом и копируются одним нажатием.

## Сценарии

**Несколько мероприятий одновременно.** Создайте по мероприятию на каждое. Места из всех открытых мероприятий
попадают в один выпадающий список на странице «Коды», с группировкой по мероприятию. Участники разных групп видят
каждый свои поля и карточки.

**Повторное мероприятие с теми же полями.** «Новое мероприятие → По образцу» копирует поля и карточки, но не места
и не пароли. Затем загрузите новый CSV с местами.

**Перенос настроек на другую установку.** В мероприятии нажмите «Скачать шаблон»: получится JSON с полями и
карточками, без мест и паролей. На другой установке: «Мероприятия → Создать из JSON».
Если в JSON есть поле `slots`, места создадутся сразу.

**Свой набор полей.** Поля данных и карточки не привязаны к конкретным сервисам. Для лабораторной достаточно двух
полей (логин и пароль), для экзамена с несколькими сервисами можно завести столько полей и карточек, сколько нужно.

**Старый `config.json`.** Список записей `[{"login": "...", "password": "..."}, ...]` можно загрузить на странице
«Мероприятия → Создать из JSON» (поля возьмутся из ключей) или из командной строки:

```bash
docker compose cp config.json web:/tmp/config.json
docker compose exec web python manage.py import-json /tmp/config.json --exam "Название"
docker compose exec web rm /tmp/config.json
```

Исходный файл после импорта удалите: в нём пароли открытым текстом.

**Забыли пароль владельца.**

```bash
docker compose exec web python manage.py create-admin
```

Команда создаёт нового владельца. Старого можно удалить на странице «Админы».
